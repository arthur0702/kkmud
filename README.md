# KK MUD 圖形用戶端

給文字 MUD《萬王之王》（King of Kings，`kks.muds.idv.tw:4000`）用的網頁圖形用戶端。

它在本機跑一個小型 Node.js 代理，代理透過 telnet 連上 MUD，並處理 Big5 ↔ UTF-8 轉換。瀏覽器這邊會把伺服器送來的文字同時畫成：

- 3D 房間場景（內建西洋棋風格，不需任何遊戲素材）
- 小地圖
- 商店、背包、留言板面板

原本的文字終端機仍然完整保留，所有指令照樣可以直接打。

> 本專案是玩家自製的非官方工具，與《萬王之王》的營運單位沒有任何關係。
>
> 本專案的程式碼與文件由 AI 產生，詳見 [AI 產生聲明](#ai-產生聲明)。
>

## 功能

### 連線與終端機
- 本機代理以 telnet 連上 MUD，處理 Big5 編碼並支援 ANSI 顏色。
- 伺服器關閉回顯時（輸入密碼），輸入框自動改為密碼模式，該行既不顯示也不寫入紀錄。
- 關掉或重新整理分頁不會斷線：連線由本機代理維持，重新打開頁面時會補上最近 500 則輸出。
- 每個帳號、每次連線各寫一份紀錄檔到 `logs/`，可拿來調整辨識規則。

### 圖形畫面
- **兩種畫面**（工具列「畫面」切換）：
  - **西洋棋**（預設，內建）：人物和怪物都是西洋棋子，地板是依地形配色的棋盤格，通往出口的路是同色系的色塊，樹木、岩石等景物用簡單的立體形狀表示。不需要任何遊戲素材。
  - **官方素材**：原版的 3D 人物與怪物模型、地磚和景物圖片，需要另外安裝遊戲素材。
- **房間場景**：依房間名稱與描述判斷地形（城市、室內、森林、洞穴、雪地、沙漠、水邊……），配上對應的地板與景物。
- **出口按鈕**：每個出口都有按鈕。上下樓（up/down）畫成樓梯和地洞，其他特殊出口放在小地圖下方。
- **人物與怪物**：
  - 西洋棋畫面：你是金色的國王（女性角色是皇后），NPC 是白棋，怪物是黑棋：
    - NPC 依身分選棋子：守衛和騎士是騎士、祭司和法師是主教、國王和女王是王與后，其他人是兵；
    - 怪物依體型選棋子：大型是城堡、中型是主教、野獸是騎士、小動物是兵；
    - 物品是小金塊，屍體是倒下的棋子；
    - 攻擊時前衝、受傷時抖動並閃紅光、死亡時倒下。
  - 官方素材畫面：依名稱對應怪物模型或職業外觀，並有待機、走路、攻擊、受傷、死亡動畫。
- **名牌選單**：點名牌會出現動作選單，例如查看、戰力評估（`consider`）、攻擊、撿起、全部拾取、看留言。
- **戰鬥**：戰鬥時名牌顯示對方剩餘的血量比例，怪物死後原地留下屍體。
- **其他人進出**：有人走進或離開房間時，畫面直接跟著更新，不必重新 `look`。
- **法術語音**：施法成功、伺服器印出咒文（例如「妳喃喃唸道 : 摩里多納 ～～ 賀魯 ...」）時，播放該法術的施法語音；伺服器說「你」用男聲、「妳」用女聲。施法失敗不會出聲。可用工具列的「法術語音」開關，需要遊戲素材。
- **房間內的指令字**：描述裡「存(deposit)」這類中英對照的字，以及夾在中文裡的 `list` 之類動詞，會變成可點的按鈕。

### 小地圖
- 依走過的方向自動畫出房間格子圖，連上下樓層也記錄。
- 傳送、回城這類跳躍後，會自動找回已知的房間。不同區域各自一張圖。
- 野外繞圈或格子對不上時，會記住實際走過的路：
  - 繞回原地時接回已知的房間，不會再多畫一個。
  - 擋路的房間會被推開，而不是被覆蓋。
- 每個帳號自動存檔。
- 點小地圖會打開大地圖，可以：
  - 拖曳、縮放；
  - 切換區域與樓層；
  - 匯出 PNG 圖片；
  - 匯出或匯入 JSON；
  - 刪除區域。

### 面板
- **商店**：在店裡送出 `list` 後，商品整理成清單，同樣的商品合併成「×N」，每項附「購買」「查看」按鈕。長清單會自動合併分頁。
- **背包**：送出 `i` 後顯示「使用中／攜帶」兩區和負重。
  - 每件物品有拿武器、卸下、穿上、脫下、查看按鈕。
  - 同名物品自動編成 `ring`、`ring 2`……
- **留言板**：站在有留言板的房間時，上方出現「留言板（N 未讀）」按鈕。
  - 列表最新的在上面，點標題就能閱讀。
  - 長文會自動翻頁到底，整篇一次顯示。
  - 有上一篇、下一篇、讀新留言。

### 多帳號
- 可以同時連線多個帳號，每個帳號開在自己的分頁（`?s=<帳號 id>`）。
- 每個帳號有各自的自動登入、斷線重連、別名、觸發、定時、快捷鍵和小地圖。
- 請遵守伺服器對多重登入的規定。

## 需求

- [Node.js](https://nodejs.org/) 18 以上。沒有任何 npm 套件依賴，不必執行 `npm install`。
- 新版的 Chrome、Edge 或 Firefox。
- 3D 函式庫 three.js（r160）：
  - 如果素材資料夾裡有一份（`viewer/vendor/three/`），就用本機那份；
  - 沒有的話，從 jsDelivr CDN 載入同一版本，第一次需要網路。

## 安裝與啟動

```bash
git clone <此專案網址> kkmud
```

```bash
cd kkmud
```

```bash
npm start
```

然後用瀏覽器打開 <http://localhost:8140/>。Windows 也可以直接雙擊 `start.bat`，它會啟動代理並自動打開頁面。

第一次使用的步驟：

1. 按「設定」→「帳號」，填入角色英文名字和密碼。
2. 視需要勾選「自動登入」「斷線自動重連」。
3. 按「連線」。

不填帳號也可以：直接連線，在指令列手動登入。

只想看看畫面、不連線的話，按上方的「示範」，會用內建的示範文字依序展示房間、戰鬥、商店、背包、留言板。

代理只聽 `127.0.0.1`，並且拒絕其他網站發來的請求。只有這台電腦上的瀏覽器能用它。

## 遊戲素材（選用）

**本專案不包含任何遊戲素材**，包括模型、貼圖、音樂。沒有素材也能完整遊玩：

- 畫面自動使用內建的**西洋棋風格**（棋子、依地形配色的棋盤地板、簡單景物），這部分完全由程式產生；
- 文字終端機、小地圖、所有面板與自動化功能都照常運作；
- 只有背景音樂、法術語音和「官方素材」畫面需要素材；
- 終端機會出現「找不到遊戲素材，使用內建的西洋棋畫面」提示。

如果你自己合法持有官方圖形用戶端，可以把它的資源轉出成以下結構，放在本專案旁邊的 `../iKing_official/_extracted/`，或用環境變數 `KK_ASSETS` 指定位置：

```
_extracted/
  gltf/bin/player/<職業>_<m|w>.glb     人物模型（例如 warrior_m.glb）
  gltf/bin/monster/<名稱>/*.glb         怪物模型
  gltf/bin/building/item.glb, corpse.glb
  sprites/<MapPatternXX|GobBmpXX>/RID*.png 與 sprites/index.csv   地磚、景物
  text/gobname.bin                      景物名稱（JSON）
  audio/sound/bgm/*.wav                 背景音樂
  audio/sound/voice/<編號>_<m|f>_<n>.wav  施法語音
  text/spltable.bin                     法術表（法術英文名稱 → 語音編號）
  viewer/vendor/three/                  three.js r160（可省略，會改用 CDN）
```

資源轉出工具不在本專案內，素材的著作權屬於原權利人。請勿把素材上傳到公開的地方。

## 操作說明

| 操作 | 說明 |
|---|---|
| Enter | 送出指令列的內容（空白也會送出，可用來回應分頁） |
| ↑ / ↓ | 叫出上一個／下一個歷史指令（每個帳號各自保存最近 300 筆，重新整理後仍在；輸入密碼時打的字不會記錄） |
| 數字鍵盤 8 2 4 6 / 7 9 1 3 | 北、南、西、東 / 西北、東北、西南、東南 |
| 數字鍵盤 − / + | 上樓 up / 下樓 down |
| 數字鍵盤 5 / 0 | `look` / 背包 `i` |
| 數字鍵盤 / / * | `inventory` / `score` |
| Alt+1 … Alt+0 | 第 1～10 個快捷按鈕 |
| Esc | 關閉名牌選單 |

數字鍵盤只在指令列空白、而且沒有打開設定視窗時才會送出指令，避免打字時誤觸。方向鍵不會移動人物。

## 自動化：別名、觸發、定時、快捷鍵

都在「設定」裡，每個帳號分開保存。自動化由本機代理執行，所以就算關掉分頁也會繼續運作。

### 指令清單的寫法

別名、觸發、定時、快捷鍵的「指令」欄位都用同一種寫法：

```
look;#wait 500;get all from corpse
```

- `;` 分隔多個指令。
- `#wait 毫秒` 會暫停一下再送下一個。
- 指令本身也可以是另一個別名。

### 各項功能

- **別名**：例如名稱 `gc`、指令 `get all from corpse`。
  - `%1`～`%9` 代入第幾個參數，`%*` 代入全部參數。
  - 例如 `say2` 設成 `say %1 and %*`。
- **觸發**：伺服器送出符合的行時自動執行。
  - 可以用一般文字，也可以用正規表示式；正規表示式的擷取群組用 `%1` 帶入。
  - 每個觸發有冷卻時間（最短 0.2 秒），同一波洪水般的訊息只會觸發一次。
- **定時**：每 N 秒執行一次，最短 5 秒。
- **快捷鍵**：10 個按鈕排在指令列上方，用滑鼠點或按 Alt+數字都可以。點空白的按鈕會直接打開設定。

### 防洪機制

自動送出的指令在 10 秒內超過 30 個時，自動化會暫停，以免失控的觸發把角色送進無限迴圈。

暫停時狀態列會顯示「自動指令已暫停」，下次手動連線時解除。你自己打的指令不受這個限制。

### 自動登入失敗

自動登入遇到密碼錯誤只會嘗試一次，之後停止，不會反覆重試。

## 資料存放與安全

| 位置 | 內容 | 注意 |
|---|---|---|
| `data/profiles.json` | 帳號設定與自動化規則，**包含明文密碼** | 已列入 `.gitignore`，請勿上傳或分享 |
| `data/maps/<帳號>.json` | 小地圖存檔 | 可用大地圖的「匯出 JSON」備份 |
| `logs/session-*.log` | 每次連線的完整紀錄 | 含其他玩家名字與聊天，已列入 `.gitignore` |

- 密碼只存在本機的 `data/profiles.json`。不會寫進紀錄檔，也不會傳回瀏覽器（頁面上只會知道「有沒有設定密碼」）。
- 輸入密碼時（伺服器關閉回顯），那一行不會顯示在畫面，也不會寫入紀錄。
- 代理只綁定 `127.0.0.1`，並檢查 `Origin` 和 `Sec-Fetch-Site`，拒絕其他網站的跨站請求。

## 調整文字辨識規則

所有「怎麼從文字看出是什麼」的規則都集中在 [`public/config.js`](public/config.js)，大部分是從實際連線紀錄歸納出來的，例如：

- `PARSER`：房間標題、出口行、提示符號、分頁、HP/MP、戰鬥訊息、人物進出、背包、留言板。
- `TERRAIN`：房間名稱或描述 → 地磚與景物。
- `MONSTERS` / `PEOPLE` / `FEMALE`：名稱 → 怪物模型、職業外觀、性別。
- `ACTIONS`：名牌點下去的動作選單。
- `ROOM_VERBS`：房間描述裡會變成按鈕的動詞。
- `SHOP` / `INVENTORY` / `BOARD`：商店、背包、留言板使用的指令。

遇到辨識不正確的情況，可以拿 `logs/` 裡的紀錄重播來檢查：

```bash
node tools/replay.mjs logs/session-XXXX.log
```


## 開發歷程

依完成順序整理。

### 素材研究（專案外的前置工作）
1. 分析並轉出《萬王之王》官方圖形用戶端（UGkk / iKing）的資源。
   - 模型轉成 glTF（含動畫）；
   - 地磚與景物轉成 PNG，建立 `sprites/index.csv`；
   - 背景音樂與景物名稱表。
2. 做了一個網頁版的 glTF 模型瀏覽器，用來確認轉出結果。
   - three.js r160 也是在這一步放進 `viewer/vendor/`。

### 用戶端主體
3. 本機代理：telnet 連線、Big5 ↔ UTF-8、ANSI 顏色、SSE 串流、重新整理後補上最近輸出、連線紀錄檔。
4. 文字解析器：
   - 依出口行辨識房間，取出標題、描述和房間裡的東西；
   - 用提示符號（`> `）對應指令與回應；
   - 處理「未完繼續」分頁。
5. 3D 房間場景：地形判斷、地磚與景物、出口按鈕、人物與怪物模型、名牌與動作選單。
6. 戰鬥動畫與血量顯示、怪物死亡留下屍體、撿東西時畫面同步。
7. 小地圖：依移動方向建格子圖、多區域、跳躍後定位、每帳號自動存檔、大地圖視窗、匯出 PNG/JSON 與匯入。

9. 房間描述裡的中英對照指令字變成按鈕。
10. 商店清單面板：合併同名商品、跨分頁合併、購買與查看按鈕。

### 多帳號與自動化
11. 多帳號：每個帳號獨立連線與分頁，帳號設定存在本機。
12. 自動登入、斷線自動重連、密碼錯誤不重試、密碼不外洩（不寫紀錄、不回傳瀏覽器）。
13. 別名（參數 `%1` `%*`、`;` 與 `#wait`）、觸發（文字或正規表示式、冷卻時間）、定時；全部在代理端執行，關掉分頁也繼續。
14. 防洪機制：自動指令過多時暫停。

## 已知限制與待辦

- 文字辨識是用規則推測的。遇到格式不同的商店、特殊房間或其他語系訊息時可能認不出來，需要依紀錄調整 `config.js`。
- 小地圖只是依走過的方向畫出的示意圖：
  - MUD 本身沒有座標，單向通道或扭曲的空間可能畫得不準；
  - 可以刪除區域重畫。
- 背包空的時候伺服器顯示的訊息，還沒在正式伺服器上確認。
  - 多個字組成的物品 id 已確認可用，紀錄中 `buy strong pill` 成功買到大力丸。
- 留言板只做閱讀。發文（`post`）和回覆（`followup`）需要輸入多行內文，請直接在指令列操作。
- 帳號密碼以明文存在本機。如果電腦有其他人使用，建議不要儲存密碼，改為每次手動輸入。
