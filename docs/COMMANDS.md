# 指令與操作說明

本文件分成兩部分：

- **A.** 萬王之王 MUD 的遊戲指令，依遊戲內 `help cmds` 分類整理。
- **B.** 本圖形用戶端的操作方式：每個遊戲動作在畫面上怎麼點、怎麼按。

遊戲玩法與地點介紹見 [新手攻略](GUIDE.md)。

> 本文件由 AI 依遊戲內說明與連線紀錄整理產生（見 README 的「AI 產生聲明」）。指令的詳細用法一律以遊戲內 `help <指令>` 為準。

## A. 遊戲指令

### 移動

| 指令 | 縮寫 | 說明 |
|---|---|---|
| `north` / `south` / `east` / `west` | `n` `s` `e` `w` | 北、南、東、西 |
| `northeast` / `northwest` / `southeast` / `southwest` | `ne` `nw` `se` `sw` | 東北、西北、東南、西南 |
| `up` / `down` | `u` `d` | 上、下 |
| `go <方向>` | | 往某方向走 |
| `recall` | | 回到冒險者之家 |
| `look` | `l` | 看這個房間 |
| `look <id>` | | 看某個人、怪物或物品 |

伺服器的房間格式：

```
冒險者之家 -                         ← 房間名稱
    這裡是著名的冒險者之家, ...      ← 描述
    這裡明顯的出口是 down、south、north、west、east 和 up。
  女服務生 悠妮(Waitress)            ← 在場的人物與物品，括號內是 id
  酸甜苦辣留言板(Board) [ 35 張留言﹐35 張未讀 ]
>                                    ← 提示符號，表示可以輸入下一個指令
```

操作人物或物品時用括號裡的 **id**（不分大小寫），例如 `look waitress`、`kill adventurer`。

## B. 用戶端操作

### 畫面配置

| 區域 | 內容 |
|---|---|
| 上方工具列 | 連線、帳號切換、設定、畫面（西洋棋／官方素材）、角色外觀（官方素材畫面用）、背景音樂、法術語音、ID 列表、查看四周、背包、留言板（所在房間有留言板時才出現）、● 錄製、▶ 播放、示範 |

| 左側 | ID 列表開啟時自成一欄：小地圖、ID 列表、體力與法力條，3D 畫面在右邊不會被蓋住 |
| 中間 | 3D 房間：地形、人物與怪物（含名牌）、出口按鈕、上下樓的樓梯和地洞 |

### 鍵盤

| 按鍵 | 送出的指令 | 條件 |
|---|---|---|
| 數字鍵盤 8 2 4 6 | `north` `south` `west` `east` | 指令列空白 |
| 數字鍵盤 7 9 1 3 | `northwest` `northeast` `southwest` `southeast` | 指令列空白 |
| 數字鍵盤 − / + | `up` / `down` | 指令列空白 |
| 數字鍵盤 5 | `look` | 指令列空白 |
| 數字鍵盤 0 | `i` | 指令列空白 |
| 數字鍵盤 / | `inventory` | 指令列空白 |
| 數字鍵盤 * | `score` | 指令列空白 |
| Alt+1 … Alt+0 | 第 1～10 個快捷按鈕 | |
| Enter | 指令列的內容；空白時送出 Enter，可用來翻分頁 | |
| ↑ / ↓ | 叫出上一個／下一個歷史指令（每個帳號各自保存最近 300 筆，重新整理頁面後仍在） | |
| Esc | 關閉名牌選單；沒有選單時關閉背包、商店、留言板面板 | |

方向鍵不會移動人物。數字鍵盤在以下情況不會送出指令：

- 指令列有字；
- 在其他輸入框裡打字；
- 打開了設定視窗；
- 按住 Ctrl、Alt、Meta；
- 正在輸入密碼。

| 撿東西 | 點物品名牌 →「撿起」 | `get <id>` |

| 重新看房間 | 工具列「查看四周」 | `look` |
| 存款、購買這類房間動作 | 房間描述下的按鈕（例如「存款 deposit」） | 需要參數的會先填進指令列，補上數量或物品後按 Enter |
| 看房間裡提到的東西 | 描述下的「查看 xxx」按鈕 | `look xxx` |

### 法術語音

施法成功時，伺服器會印出你唸的咒文，例如 `妳喃喃唸道 : 摩里多納 ～～ 賀魯 ...`，這時會播放這個法術的施法語音。

- 伺服器說「你」用男聲、「妳」用女聲；同一個法術有好幾句時隨機挑一句。
- 施法失敗（例如「你要有目標才能施法。」）不會出聲。
- 由別名、快捷按鈕、觸發送出的 `cast` 也會播放；法術名稱可以只打開頭，例如 `cast firebal`。
- 工具列的「法術語音」可以關掉。
- 需要遊戲素材裡的語音檔。語音檔只有編號，法術和編號的對照表在 `public/config.js` 的 `SPELL_VOICE`：
  - 有 22 個法術已經用實際咒文比對確認，其餘是依前後順序推算的；
  - 如果某個法術聽起來不對，改那裡的編號即可。

### ID 列表

畫面左側的列表，最多 15 個：

```
#0  hero        你自己
#1  guard       城門衛兵
#2  guard 2     城門衛兵
#3  bard        流浪的吟遊詩人
#4  shortsword  短劍
```

- `#0` 是你自己，取自設定裡這個帳號的角色英文名字。
- 接著是房間裡的人物和怪物，最後是物品和屍體。有人進出、撿起東西、怪物死亡時會即時更新。
- 在指令列打 `#編號` 就代表那個 id：`look #0` 送出 `look hero`，`kill #2` 送出 `kill guard 2`。
- 同樣 id 的第二個寫成 `guard 2`，這是 MUD 指定「第二個」的寫法。
- 列表沒有的編號（例如 `#9`）和 `#wait` 不會被替換。輸入密碼時也不會替換。
- 點列表的一列，會把 `#編號` 填入指令列游標的位置。
- 工具列的「ID 列表」可以開關。

**`#99`：向你打招呼的人**

畫面出現「小雨很熱情地對妳打招呼。」這類訊息時，會找出「小雨」的 id 存進 `#99`，列在 ID 列表最下面，之後 `look #99`、`tell #99 你好` 都指向他。

- 本機代理會從伺服器印出的每個「名字(Id)」記住名字和 id 的對應，例如房間清單、`score`、`who`、留言板作者；啟動時也會讀過去的連線紀錄。記錄存在 `data/names.json`，所有帳號共用，例如一個帳號的 `score` 讓其他帳號也知道這個角色的 id。關掉分頁時觸發照樣能用。
- 走進房間的人（「小雨走了過來。」只有名字）也會用這份記錄補上 id。
- 如果還沒看過這個名字的 id，`#99` 會顯示「?」並提示；等他出現在房間清單或 `who` 之後就查得到。
- `#99` 依帳號保存，重新整理後仍在。

`#編號` 在指令列、別名、快捷按鈕、觸發、定時裡都可以用。例如觸發「很熱情地對妳打招呼」設成 `cast bless on #99`，會對打招呼的人施法；如果當下還不知道那個 id，這一個指令會略過並提示，而不是送出 `#99` 讓伺服器回「這裏沒有這個人」。

### 錄製與播放

1. 按工具列的「● 錄製」，按鈕變成「■ 停止錄製（已錄幾個）」。
2. 照平常一樣操作：打字、數字鍵盤、點名牌選單、出口、快捷按鈕送出的指令都會記下，連同和上一個指令相隔幾秒。
3. 再按一次結束，錄製會存成「錄製 月/日 時:分」並打開錄製清單。

錄製清單（工具列「▶ 播放」）：

| 項目 | 說明 |
|---|---|
| 等待秒數 | 上一個指令送出後再等幾秒送出這一個（第一列從按下播放開始算），可到 0.1 秒 |
| `@秒數` | 從開始播放算起的時間，只是顯示 |
| 指令 | 可以直接改；可用 `;` 分隔多個指令、別名、`#1` 之類的 ID 變數 |
| ↑ ＋ ✕ | 上移、在下面插入一列、刪除這一列 |
| 時間 × 倍數 | 所有等待秒數乘上倍數，例如 0.5 快一倍、2 慢一倍 |
| 重複 | 播放幾次；0 = 一直重複到按停止 |
| 新增／複製／刪除 | 自己寫一段新的、複製目前這段、刪除目前這段 |

播放時目前送出的那一列會被框起來，工具列顯示「■ 停止播放 第幾個/共幾個」，按一下就停止。注意：

- `#編號` 是照打字的樣子記下、播放時才換成當下的 id，所以房間裡的東西不同時可能指到別的對象。
- 伺服器要求輸入密碼的時候不會錄製，也不會播放。
- 錄製依帳號存在這台電腦的瀏覽器裡。播放在網頁中進行：關掉或重新整理分頁、斷線都會停止。
- 播放送出的指令和打字一樣受伺服器限制；太快的錄製請用「時間 ×」放慢。

### 商店面板

1. 在店裡送出 `list`，或按描述下的「商品列表」按鈕。
2. 清單會自動整理成面板：
   - 同樣的商品合併顯示「×N」；
   - 每項有「購買」（`buy <id>`）和「查看」（`look <id>`）。
3. 清單有好幾頁時，按面板下方的「下一頁」，內容會合併在同一個面板裡。
4. 離開商店時面板自動關閉。

### 背包面板

1. 按工具列「背包」或數字鍵盤 0，會送出 `i`；數字鍵盤 `/` 送出 `inventory`，效果相同。
2. 面板分成「使用中」（打勾）和「攜帶」兩區，右上角顯示負重。
3. 每件物品的按鈕：

| 物品狀態 | 主要按鈕 | 其他按鈕 |
|---|---|---|
| 攜帶中的武器 | 拿武器（`wield`） | 穿上、查看 |
| 攜帶中的防具 | 穿上（`wear`） | 拿武器、查看 |
| 使用中的武器 | 卸下（`unwield`） | 脫下、查看 |
| 使用中的防具 | 脫下（`remove`） | 卸下、查看 |

4. 按下動作後會自動再送一次 `i`，畫面上的打勾隨即更新。
5. 同名物品會自動加上編號，例如第二個戒指是 `small ring 2`。

### 留言板面板

1. 站在有留言板的房間，按工具列「留言板（N 未讀）」，或點留言板名牌選「看留言」，會送出 `look board`。
2. 列表的最新留言在最上面，Re 回覆會縮排，讀過的變灰。
3. 點標題會送出 `read <n>`，長文自動翻到最後，整篇顯示在面板裡。引用（`>` 開頭）的行會換成另一種顏色。
4. 面板按鈕：

| 按鈕 | 動作 |
|---|---|
| ← 列表 | 回到列表 |
| 上一篇 / 下一篇 | 讀相鄰的文章 |
| 讀新留言 | `read new` |
| ↻ | 重新讀列表 |
| ✕ | 關閉；文章還停在分頁時會先送 `q` 離開 |

5. 自己在指令列打 `read 5` 也會打開面板，但不自動翻頁，要按「下一頁」。

### 小地圖與大地圖

- 移動時自動畫圖，目前位置會標示出來，上下樓層和不同區域分開記錄。
- 點小地圖打開大地圖，可以：
  - 拖曳移動、滾輪縮放；
  - 「目前位置」「全部顯示」；
  - 切換區域與樓層；
  - 「匯出圖片」（PNG）、「匯出 JSON」、「匯入 JSON」；
  - 「刪除區域」「全部清除」。
- 小地圖每個帳號自動存檔，重新整理頁面不會遺失。

### 設定視窗（工具列「設定」）

| 分頁 | 內容 |
|---|---|
| 帳號 | 名稱、主機與埠號、角色名字與密碼、自動登入、斷線自動重連；新增或刪除帳號；在新分頁開啟某個帳號 |
| 別名 | 名稱與指令。指令中 `;` 分隔多個指令，`#wait 500` 暫停 0.5 秒，`%1`…`%9` 代入參數，`%*` 代入全部參數 |
| 觸發 | 符合文字或正規表示式時執行指令，可設冷卻秒數，正規表示式的群組用 `%1` 帶入 |
| 定時 | 每 N 秒（最少 5 秒）執行一次 |
| 快捷 | 10 個按鈕的名稱與指令，寫法同別名，對應 Alt+1～0 |

範例：

| 類型 | 設定 | 效果 |
|---|---|---|
| 別名 | 名稱 `gc`，指令 `get all from corpse` | 打 `gc` 就搜屍 |
| 別名 | 名稱 `bp`，指令 `buy %1;#wait 300;i` | `bp strong pill` 買完後自動看背包 |
| 觸發 | 文字 `死了。`，指令 `gc`，冷卻 1 秒 | 怪物一死就自動搜屍 |
| 快捷 | 名稱「回城補血」，指令 `recall;#wait 1000;hp` | 一鍵回城並看體力 |

自動送出的指令在 10 秒內超過 30 個時，自動化會暫停，下次手動連線時解除。使用自動化請遵守伺服器規定。

### 多帳號

- 在設定的「帳號」分頁按「＋ 新增帳號」，存好後按「在新分頁開啟此帳號」，每個帳號各自一個分頁（網址 `?s=<帳號 id>`）。
- 每個帳號的連線、自動化、小地圖互相獨立。
- 關掉分頁不會斷線，重新打開就接回原本的連線。

### 示範模式

按工具列「示範」，會用內建的示範文字依序展示房間、戰鬥、商店、背包、留言板，不會連線。重新整理頁面即可結束。
