# 萬王之王 MUD 新手攻略

這份攻略是整理實際連線到 `kks.muds.idv.tw:4000` 的紀錄、以及遊戲內 `help` 說明寫成的。

- 引號裡的文字是伺服器的原文。
- 地點和路線都以實際走過的紀錄為準。
- 遊戲內容可能隨時調整，有出入時請以遊戲內的 `help <主題>` 為準。
- 搭配本用戶端的操作方式，見 [指令與操作說明](COMMANDS.md)。

> 本文件由 AI 依連線紀錄整理產生（見 README 的「AI 產生聲明」）。

---

## 1. 第一次進入遊戲

1. 連線後，伺服器會先問「您的英文名字(新人物請輸入'new')」。新人物輸入 `new`，照提示建立角色。
2. 進入遊戲後先看說明，`help` 列出的主題中，這兩個是官方標明必讀的：
   - `help rules`：「每個遊戲都有必須遵守的規則, 必讀。」
   - `help newbie`：「超級新新手必讀。」
3. 其他常用的說明主題：

| 主題 | 內容 |
|---|---|
| `help cmds` | 常用指令列表 |
| `help classes` | 可以加入的職業 |
| `help advance` | 提升等級 |
| `help weapon` / `help armor` | 武器、防具簡介 |
| `help magic` | 簡單的法術列表 |
| `help gold` | 財富的意義 |
| `help kingdom` / `help family` | 國家、家族 |
| `help pk` | PK 簡介 |
| `help faq` | 最近常見問題 |
| `help board` | 留言板用法 |

任何指令都可以用 `help <指令>` 查詳細用法。

## 2. 主城史坎布雷

遊戲的起點和「回城」的落點都是**冒險者之家**。它是史坎布雷城裡的一座大廳，中央有冒險者的精神象徵「探尋之火」。

### 冒險者之家周邊

```
                 魔法塔閣樓
                     ↑ up
                 法術研習室        list 查看、study 研習法術
                     ↑ up
                  訓練廳           train 訓練技能、advance 升級、list、cost
                     ↑ up
 郵局 ← west ─  冒險者之家  ─ north → 提洛爾街（城內主街）
                     ↓ down        ↓ south
              世界新聞發送站      走道 ─ east → 自由者殿堂
                     ↓ down        │  ─ west → 資料展示室入口 → 展覽室（歷年展覽）
           Summer98 大網聚兌獎處   ↓ south
                                  儲藏室
```

### 城內地標

提洛爾街、路口、蠍尾街都分成好幾段同名的街道，走的時候請看小地圖。

| 地點 | 怎麼走（依紀錄） | 可以做什麼 |
|---|---|---|
| 雷的藥店 | 提洛爾街往北 | `list` 看藥品，`buy` 購買 |
| 結婚禮堂 | 提洛爾街往北 | `marry` 結婚 |
| 諾蘭雜貨店、蒂娜的店 | 提洛爾街往南 | 雜貨 |
| 綠色矮人酒吧 | 路口往北 | 史坎布雷唯一的酒吧，有酒保烏里和新手冒險者 |
| 築城大師的家 | 路口往西 | 與國家建設有關 |
| 月之神殿 → 時空魔法陣 | 路口往東，再往東 | `pray` 祈禱 |
| 蓋茲裝備店 | 蠍尾街往東 | `list`、`buy`、`sell`、`value` 估價 |
| 查克銀行 | 蠍尾街往東 | `deposit` 存款、`withdraw` 提款、`transfer` 轉帳 |
| 史坎布雷城門 | 蠍尾街往南 | 出城往東是「道路」，通往野外 |
| 十字路口 → 巴別塔前 | 蠍尾街往南、再往東 | |

### 回城

在任何地方輸入 `recall`，伺服器會回應「你祈求神把你帶回冒險者之家 ...」，然後你就回到冒險者之家。迷路或打不過怪物時很好用。

## 3. 角色狀態

| 指令 | 顯示內容 |
|---|---|
| `score`（或 `sc`） | 職業、稱號、等級、種族與性別、六項屬性（力量、智慧、敏捷、毅力、體質、運氣）、身體狀況、體力與法力、武器等級與傷害範圍、防禦等級、戰鬥經驗、身上與銀行的金幣 |
| `hp` | 只看體力、法力、經驗 |
| `i`（`inventory`） | 身上物品與負重，物品前有「ˇ」的表示正在使用 |
| `skills` / `spells` | 技能、法術 |

## 4. 升級與訓練

升級在**訓練廳**（冒險者之家往上 `up`）。房間描述寫著「可以在這裏訓練(train)技能、提升(advance)等級、查看(list)訓練所需代價(cost)」。

- `list`：列出這裡能訓練的技能和上限。以戰士為例，有劍類、刀類、斧類、鎚類、矛戟類、匕首類武器、武器專家、武器格檔、盾牌防禦、人身保護、加強傷害等。
- `train [多少] <技能名字>`：訓練技能，例如 `train sword`。不帶參數時會顯示這個語法。
- `advance`：伺服器會問「你要提昇什麼 ? 等級(level)還是屬性 ?」
  - 依提示，升等級應該是 `advance level`。
  - 這點還沒在紀錄中實際驗證，屬性的寫法也請用 `help advance` 確認。
- `cost`：查看訓練需要的代價。

法術在**法術研習室**（訓練廳再往上）：先用 `list` 翻看，再用 `study` 研習。

## 5. 戰鬥

### 基本流程

1. `look <id>` 看對手，會顯示對方的外觀、傷勢和裝備。
2. `consider <id>` 評估對手強弱。
3. `kill <id>`（可簡寫 `k`）開始戰鬥，雙方會自動來回攻擊直到一方死亡或逃跑。
4. 對手死亡時會顯示「○○死了。」和「(你得到 N 點經驗。)」，原地留下屍體。
5. 用 `get all from corpse` 取出屍體上的東西。直接 `get corpse` 會說拿不起來。

### 對手的傷勢

戰鬥中伺服器會用括號描述對手和你自己的傷勢（例如「( 你受了幾處傷, 但是沒有傷到要害。 )」），由輕到重：

| 伺服器的描述 | 大約剩下 |
|---|---|
| 正處於最佳狀況 | 100% |
| 似乎受了點傷 | 90% |
| 受了幾處傷 | 75% |
| 傷到不少地方 | 50% |
| 身上到處都是傷口 | 30% |
| 渾身是血, 受傷極重 | 15% |
| 已經奄奄一息 | 5% |

百分比是本用戶端畫血條用的估計值，不是伺服器給的數字。

### 第一隻對手

綠色矮人酒吧裡的**新手冒險者**（id `adventurer`）只帶一把短劍。紀錄中打倒一隻約得到 70 點經驗，適合剛開始練手。

### 其他戰鬥指令

| 指令 | 用途 |
|---|---|
| `wield` / `unwield` | 拿起、放下武器 |
| `wear` / `remove` | 穿上、脫下防具 |
| `defend` / `undefend` | 防禦相關 |
| `wimpy` | 設定逃跑門檻 |
| `cast` | 施法 |

用法都請以 `help <指令>` 為準。

## 6. 買賣與金錢

### 裝備店（蓋茲裝備店）
- `list` 看商品。清單很長時會分頁，按 Enter 看下一頁。
- `buy <id>` 購買，例如 `buy iron sword`。
- `value <id>` 請老闆估價，`sell <id>` 賣掉。

### 藥店（雷的藥店）

`list` 會顯示「你可以買到(buy)這些東西」，紀錄中有：

| 藥品 | 價格 |
|---|---|
| 黃連解毒丸(Depoison pill) | 200 枚金幣 |
| 大力丸(Strong pill) | 100 枚金幣 |
| 藍色藥水(Blue potion) | 1200 枚金幣 |
| 綠色藥水(Green potion) | 500 枚金幣 |
| 藥膏(Plaster) | 200 枚金幣 |

- 多個字的 id 可以直接用，例如 `buy strong pill`（紀錄中回應「你買下一顆大力丸(Strong pill)。」）。
- 大力丸的說明提到可以吃（`eat`）。藥水類應該是用 `drink`，但還沒在紀錄中確認。

### 銀行（查克銀行）
- `deposit` 存款、`withdraw` 提款、`transfer` 轉帳。
- 金額的寫法請在銀行裡用 `help deposit` 等指令確認，例如不知道是 `deposit 100` 還是 `deposit 100 gold`。
- `score` 可以同時看到身上和銀行的金幣。

## 7. 野外

- 出了史坎布雷城門往東是「道路」，接著有：水晶湖畔、平原、山丘、草地、樹林、沼澤、雜樹林、海邊、前哨站與前哨站近郊、莫雷路口等。
- 海邊往西可以到【飛龍大地】～月光大道～，以及西區管制站。
- 野外很多格子的名稱和描述完全一樣，容易迷路：
  - 本用戶端的小地圖會依走過的方向記錄位置；
  - 真的迷路就用 `recall` 回城。

## 8. 溝通與社群

| 指令 | 用途 |
|---|---|
| `say` | 對同一個房間的人說話 |
| `tell` / `reply` | 密語、回覆密語 |
| `chat` | 公開頻道 |
| `tune` | 開關頻道 |
| `emote` / `semote` | 動作表情 |
| `who` | 線上名單 |
| `finger` | 查看玩家資料 |
| `ask` | 詢問 NPC |

**留言板**：冒險者之家有「酸甜苦辣留言板」，世界新聞發送站有「世界新聞公布欄」，城裡其他地方也有討論板。用法（`help board`）：

| 指令 | 用途 |
|---|---|
| `look board` | 看列表 |
| `read <編號>` | 閱讀 |
| `read new`（或 `read next`） | 讀第一篇未讀的留言 |
| `post <標題>` | 留言 |
| `followup <編號>` | 回應 |
| `discard <編號>` | 刪除自己的留言 |

**國家與家族**：
- `kingdoms` 看國家列表。
- `join` 加入國家，`rebel`、`destroy` 用於叛離與摧毀。
- 國王或大臣的專用指令見 `help king_cmds`。

## 9. 長篇輸出的分頁

輸出太長時會停在：

```
== 未完繼續 51% == (ENTER 繼續下一頁﹐q 離開﹐b 前一頁)
```

| 按鍵 | 動作 |
|---|---|
| Enter | 下一頁 |
| `q` | 離開 |
| `b` | 前一頁 |

讀留言讀到結尾時會出現「== 本文完畢，請按任意鍵繼續 ...」，要再按一次鍵才回到提示符號。本用戶端的商店與留言板面板會自動處理這兩種情況。

## 10. 規則提醒

- 遊戲規則以 `help rules` 為準。
- 伺服器的公告與討論中，多重登入（同時開很多角色）一直是被關注的議題。使用本用戶端的多帳號、觸發、定時等自動化功能前，請先確認目前的規定。
